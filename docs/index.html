QuickOps 是什么？/ What is QuickOps?

QuickOps 快维解决的是 AI 助手、终端、主机观测和审批审计相互割裂的问题。每个对话拥有一个独立的持久 Shell；用户手动操作与小维受控操作共享终端状态，但使用不同的权限入口。

QuickOps unifies an AI assistant, a terminal, live host observation, approvals, and audit. Every conversation owns one persistent Shell. Operator commands and controlled AI commands share its state while keeping separate security ingress.

核心能力 / Core capabilities

持久终端

每个会话维护独立 Shell，共享 cwd、环境变量和进程状态。

四级权限与 HITL

服务端按真实影响分类 AI 操作，在需要时触发 Agno 人机审批。

真实主机信息

运行时采集 Linux、macOS 或 Windows 主机身份与指标，而不是 UI 假数据。

Agno Harness Agent

复用 AgentOS、会话、工具、流式事件、持久化和上下文管理能力。

离线内网部署

Linux x86_64 自包含安装包，目标服务器无需联网或预装 Python、Docker、Nginx。

本地优先

SQLite 持久化，适合单用户、轻量、可持续升级的运维工作台。

常见问题 / FAQ

QuickOps 是普通 Web Terminal 吗？

不是。它包含一个面向操作者的持久终端，但还提供 AI 会话、共享 Shell 状态、真实主机观测、四级权限、HITL 审批和审计。

QuickOps 是否支持离线安装？

支持。Linux x86_64 Release 的自包含安装器不要求目标服务器访问互联网，也不依赖系统 Python、pip、Nginx 或 Docker。

AI 发起的命令是否不受限制？

不是。小维的命令由服务端权限模式和风险分类控制；需要时进入 Agno HITL 审批。用户手动终端则由操作者本人负责。

Is QuickOps a fleet-management platform?

Not yet. The current public version focuses on one operator and the machine running QuickOps. Remote-host adapters are a future extension boundary.
