# QuickOps 快维用户使用手册

版本：试用版
适用对象：运维、实施及需要维护单台服务器的技术人员

## 1 产品用途

QuickOps 快维是一套面向单机和内网环境的 AI 运维工作台。内置运维助手“小维”，并把 AI 会话、真实终端、权限审批、主机监控、服务资产、文档和运维事件放在同一套会话中。

每个会话绑定一台目标主机和一个独立的持久终端。AI 会话与手动命令只是两种操作入口，切换时不会更换终端，也不会隐藏已有对话记录。新建会话会创建新的终端环境。

> 重要：小维会直接读取或操作当前绑定主机。执行变更前请确认页面右侧的目标主机、当前权限模式和命令内容。

## 2 首次使用

### 2.1 登录

1. 使用管理员提供的 HTTP 地址打开 QuickOps。
2. 输入部署时设置的网页登录账号和密码。
3. 登录后检查右侧“目标主机”的主机名、IP 和平台是否正确。

账号或密码由服务端环境配置。修改登录凭据后需要重启 QuickOps 服务，原登录状态会失效。

### 2.2 配置模型

打开左下角“设置”，进入“模型”。新增或编辑模型时填写：

- 显示名称、接口协议、模型 ID、Base URL 和 API Key。
- 思考模式：自动、开启或关闭。是否生效取决于模型和接口兼容性。
- 最大上下文：单位为 k tokens，例如 128 表示约 128,000 tokens。
- 图像理解：只有模型和服务端接口确实支持图片输入时才开启。
- 默认模型：新会话优先使用默认模型。

模型配置保存在服务端。已保存的配置可以编辑、停用或设为默认，但不能删除。API Key 不会通过普通设置接口返回浏览器。

### 2.3 配置工具箱

“设置 > 工具箱”管理小维可用的扩展工具。Docker、文件、Python 和网页搜索适合常见运维任务；数据库工具适合临时查询。扩展工具默认关闭，启用或停用后，从所有现有会话的下一次 AI 运行开始生效，无需新建会话。

数据库连接参数不做长期保存。参数缺失时，小维会在当前会话中询问，并在该会话和当前服务进程存活期间临时复用。

## 3 工作区说明

页面由四部分组成：

1. 左侧会话栏：新建会话、最近会话和运行状态。
2. 中间对话区：用户消息、小维回复、工具调用、审批记录和手动命令回显。
3. 底部输入区：切换 AI 会话或手动命令，选择模型和权限。
4. 右侧主机区：目标主机、实时信号和主机资产。

最近会话右侧转圈表示该会话仍在执行。任务在其他会话中完成后会显示亮点。鼠标移到状态位置可显示重命名和删除操作。

## 4 使用 AI 会话

### 4.1 提交任务

在“AI 会话”中直接描述目标，例如：

- “检查 nginx 最近 10 分钟的 502 原因，只做诊断。”
- “查看当前 GPU 显存占用和主要计算进程。”
- “分析这个日志文件，给出根因假设和验证步骤。”
- “为这次故障生成一份 PDF 复盘报告。”

建议写清目标、现象、时间范围、允许的操作和期望输出。小维会先收集证据，再根据当前权限执行或申请审批。

### 4.2 工具调用

工具调用按实际发生顺序显示在小维消息中。工具执行时默认展开，完成后自动收起。点击工具条可查看参数和结果。工具成功标记只表示该次调用已经返回，不等于问题已经解决；应以小维后续验证结论为准。

### 4.3 中止回复

小维运行时，发送按钮会变成停止按钮。点击后只中止当前会话的本次运行，其他会话中的后台任务不受影响。切换到其他会话也不会自动中止正在运行的任务。

### 4.4 快捷选项

当小维需要用户在几个方案中选择时，输入框上方会出现选项卡。点击普通选项可直接继续；“其他需求”或“自定义”可在卡片内输入具体内容后提交。提交的选择会作为用户消息保存在会话记录中。

### 4.5 编辑与分支

- 编辑：最后一条通过 AI 输入框发送的用户消息可以修改后重新发送。原消息及其后续回复不会从报告和审计数据中删除，但会从当前有效对话中隐藏。
- 分支：可从小维消息或手动命令回显创建分支。分支继承所选位置之前的历史和已挂载资产，名称采用“原会话名（1）”“原会话名（2）”。用户消息和审批消息不提供分支入口。

## 5 上传文件和图片

在 AI 会话中点击回形针上传文件，也可以直接粘贴剪贴板图片。待发送附件只属于当前会话，并显示在输入框内；切换会话不会串用附件。发送后，附件从输入框清除并保留在对应用户消息中。

图片以缩略图显示。只有当前模型配置已开启“图像理解”时，图片才会作为多模态输入交给模型。若模型不支持图片，请切换到支持多模态的模型或关闭错误的能力标记。

当会话挂载了主机资产时，发送的文件还会自动归档到该资产的文档库。普通会话附件和资产文档仍保持各自的访问范围。

## 6 使用手动命令

切换到“手动命令”后，可像终端一样输入 Shell 命令。输入框前显示当前终端路径。`cd`、环境变量和 Shell 状态会在该会话后续命令中保持，并与小维在同一会话中使用的命令工具共享。

- 按上、下方向键浏览本会话的命令历史。
- “重启终端”会结束当前 Shell 并在登录账户主目录创建新 Shell；原命令记录仍保留。
- 手动命令由用户直接操作，不经过小维的四级权限和 HITL 审批。
- 手动命令及完整服务器回显会进入会话记录，小维可通过只读终端记录工具按需查询，不会在每次请求中重复拼接全部回显。

手动命令的初始路径是 QuickOps 运行账户的登录主目录。普通账户通常为 `/home/用户名`，root 账户通常为 `/root`，并非固定的服务器根目录 `/`。

## 7 四级权限与审批

权限只约束小维发起的主机命令，不约束用户在手动命令模式下直接输入的命令。

| 权限模式 | 小维可执行的操作 | 是否需要用户审批 |
| --- | --- | --- |
| 只读模式 | 系统状态、日志、进程、GPU、文件属性等观察 | 不审批；变更不可用 |
| 审批执行 | 只读观察直接执行，任何实际变更进入 HITL | 变更需要逐次批准 |
| 替我审批 | 只读、低风险和普通可恢复变更自动执行 | 高风险、严重风险仍需批准 |
| 完全访问 | 不受 QuickOps 审批限制的主机命令 | 不审批 |

审批面板出现在输入框上方，说明工具、命令、目标和风险。一次只显示最新的可操作申请。批准只授权面板中展示的准确操作，操作系统账户本身的权限仍决定命令能否成功。

建议试用阶段默认使用“审批执行”。只有在明确理解任务范围和主机风险时才使用“替我审批”或“完全访问”。

## 8 主机资产

主机资产用于按服务保存健康状态、关键运维事件和相关文档。点击右侧服务进入资产中心。

### 8.1 新建和维护服务

填写服务名称、探测方式、探测目标和探测间隔。支持进程、系统服务、HTTP 地址和 TCP 地址。启用自动监控后，系统按间隔执行低成本只读探测，只在健康状态发生变化时记录事件。

小维也可以列出、创建、更新、探测、挂载和删除当前主机的资产。要求小维修改现有资产时，应明确资产名称和目标字段，避免误建重复服务。

### 8.2 挂载到会话

一个会话最多挂载一个服务资产。挂载后，小维可以查询该服务隔离的事件和文档，并把已验证的故障、根因、部署、配置变更、重启、恢复、长期绕行方案和关键决策记录为事件。不同资产的数据不会混入同一次检索。

### 8.3 异常守护

每个服务可以配置守护模式和守护策略：

- 只排查，不修复：默认模式。探针发现异常后，小维只做只读取证，并把结论记录到事件。
- 按策略执行安全修复：小维先取证，再按用户保存的守护策略尝试最小、可恢复的安全修复并复测。服务端会拒绝高风险和严重风险操作。

守护策略应写明排查重点、允许执行的安全措施、验证要求和必须交给人工决策的边界。不要在策略中保存密码、Token 或私钥。自动排查完成后，可从事件一键创建正式会话继续处理。

### 8.4 事件和文档

事件与文档均支持新增、查看、修改和删除。文档支持下载和站内预览；图片、PDF 直接预览，文本和已提取的 Office 内容按纯文本显示。文档库使用资产隔离的关键词检索，不依赖嵌入模型。

## 9 长会话与上下文

QuickOps 使用 Agno 会话持久化、会话摘要和工具结果压缩管理长对话。当前模型收到的是稳定指令、当前上下文纪元、必要的运行快照和滚动摘要，不会无限重复拼接全部原始工具输出。

当上下文压力达到所选模型最大上下文的 90% 时，系统在当前回复完成后创建压缩检查点，并保留最近工作集。完整原始消息、工具事件、终端命令和服务器回显仍保存在 QuickOps 中，可用于界面、报告和审计。压缩不会删除用户可见历史。

## 10 报告与复制

“导出报告”会导出完整会话，包括当前有效对话以及被二次编辑替换但需保留的历史。小维也可以生成 Markdown、文本、HTML、JSON、DOCX 或 PDF 文件，并返回可下载链接。

消息下方的复制按钮复制气泡中展示的完整内容。HTTP 内网站点无法使用部分浏览器的现代剪贴板接口时，QuickOps 会自动使用兼容复制方式。

## 11 常见问题

### 小维突然停止且没有完整回答

检查该条消息末尾的失败提示。余额不足、接口限流、API Key 无效和网络超时都会终止当次运行。修复模型服务或切换模型后，重新发送“根据以上已完成结果继续”即可。新的运行会使用当前选中的模型；已进入审批或选项等待状态的原运行会继续使用创建它时的模型。

### 切换模型后仍提示旧模型错误

先确认模型选择器已显示新模型，再发起一次新的消息。不要用旧审批面板恢复已经暂停的运行。如果新运行仍报错，请进入“设置 > 模型”检查新模型是否启用、凭据是否有效。

### Docker 工具提示无法连接 daemon

这通常表示 QuickOps 运行账户无权访问 `/var/run/docker.sock`，或 Docker 服务未启动。工具进程的权限取决于部署时选择的系统账户。使用 root 运行会扩大 Web 服务的主机权限，应仅在受控内网并配合强密码、访问隔离和停用策略使用。

### 文件上传后小维看不到

确认文件显示在已发送的用户消息中。图片还需确认模型已开启并实际支持多模态。资产文档只有在该资产已挂载到当前会话后，才能由小维从隔离文档库检索。

### 审批面板没有出现

只读命令不会触发审批。变更命令在“审批执行”中应出现面板，在“替我审批”中只有高风险或严重风险操作出现面板，“完全访问”不出现面板。若运行已经失败，应先查看失败消息，而不是等待审批。

### 终端路径或状态不符合预期

手动命令和小维命令共享同一会话终端。切换会话会切换终端；重启终端会回到运行账户主目录。可执行 `pwd`、`id` 和 `printf '%s\n' "$HOME"` 核对当前环境。

## 12 安全建议

- 仅在可信内网开放 QuickOps，使用强网页登录密码，并限制可访问 IP。
- 日常使用“审批执行”，执行删除、递归删除、磁盘、权限、服务和容器变更前仔细核对审批内容。
- 不要把账号、Token、私钥或数据库密码写进对话、守护策略、资产事件和文档说明。
- 定期备份 QuickOps 的 SQLite 数据目录和资产文档目录。
- 试用结束或不再需要远程操作时，停止 QuickOps 服务。
- 发现页面目标主机、真实 IP、平台或当前路径不正确时，先停止变更操作并联系管理员。

## 13 试用反馈建议

提交问题时请提供：会话名称、发生时间、当前模型、权限模式、操作步骤、页面截图和可公开的错误文本。不要在反馈材料中包含 API Key、网页登录密码或其他生产凭据。
